
# 911 Calls Data Analysis

## Project Overview
This project analyzes 911 emergency call data to identify patterns and trends in emergency calls.

## Objective
The objective of this project is to analyze 911 calls based on reason, date, time, day of week, and month.

## Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Analyzed the most common emergency call reasons
- Analyzed calls by day of the week
- Analyzed calls by month
- Analyzed daily call trends
- Compared EMS, Fire, and Traffic calls
- Analyzed calls by day and hour
- Analyzed calls by month and hour
- Created heatmaps and clustermaps
